# JSOS Project Instructions

## Persistent task state

- Before planning, inspecting, or modifying this project, read `TASK_STATE.md`.
- At the end of every project work session, update `TASK_STATE.md` before the final response.
- Update it after code/document changes, verification, deployment, database work, or decisions that materially change the next step.
- Keep the five fixed sections: `当前目标`、`已完成`、`正在处理`、`当前问题`、`下一步`.
- Replace stale status instead of appending a chronological transcript. Keep it concise, factual, and sufficient for a new session to resume safely.
- Preserve unresolved decisions and verification needs. Never record passwords, API keys, access tokens, or other secrets.
- Do not mark work completed unless it was actually implemented and verified. Distinguish local changes, remote database changes, and production deployment.
