# JSOS 固定评分标准 v1.0

三项能力均采用 1–5 分；证据不足使用 null。任一关键项 ≤2 分时建议补强。

## 传达性 Communication

- 1：核心意思大部分无法传达，严重依赖中文或教练答案。
- 2：能传达部分简单信息，但经常需要提示或确认，核心任务未完整完成。
- 3：基本完成主要沟通目标，偶尔误解、遗漏或需要重新说明。
- 4：清楚完整地传达主要信息，能独立处理一般追问和简单变化。
- 5：准确、自然、有效地传达复杂信息，并能根据对方反应调整表达。

## 流利度 Fluency

- 1：频繁长停顿，难以组成完整句子或维持对话。
- 2：停顿和重复明显，严重依赖提示，只能使用短句逐步表达。
- 3：能持续完成对话，但复杂内容中仍有明显停顿、自我修正或重复。
- 4：大部分表达连贯，偶尔选词停顿且不影响交流节奏。
- 5：表达持续、自然、稳定，能适应打断和话题变化。

## 发音 Pronunciation

- 1：大量语音难以辨认，经常需要重复。
- 2：明显发音问题较多，偶尔造成误解。
- 3：大部分可听懂，长音、促音、节奏或语调偶尔不准确。
- 4：发音清楚，节奏与语调整体自然，很少需要重复。
- 5：发音清晰稳定，长音、促音、拨音、节奏和语调控制良好。

发音必须依据本次 Voice 音频；语音证据不足时返回 null。只统计明确观察到的错误，不把转录偏差当作用户错误。
