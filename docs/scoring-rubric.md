# JSOS 固定评分标准 v1.0

三项能力均采用 1～5 分；证据不足使用 `null`。不得为了鼓励而虚高评分，两个等级之间选择较低等级。评分依据只来自当前聊天中的实际训练。

完成状态定义：

- 独立完成：没有获得关键词、句首、选项或完整答案，仅通过真实交流中的正常重复、澄清而完成。
- 提示完成：获得关键词、句首或选项后完成。
- 跟读完成：教练给出完整句后复述。

跟读完成不能作为独立能力证据；提示完成只能作为有限能力证据。帮助后更换条件进行二次验证并独立完成，才可按独立完成计入评分。

以下情况不能算独立完成：教练根据关键词替用户补全意思；教练猜测乱码、地名或需求后继续；用户回答未完成或没有回应问题；用户只复述教练给出的完整答案；需要二次验证但尚未验证。AI 最终猜对意图，不等于用户已经清楚、独立地传达。

评分判断沟通任务是否完成，不检查用户是否逐字说出任务中的目标表达。目标表达是参考说法；自然同义表达只要在真实场景中实现相同沟通目的，应按实际完成状态计入。反之，即使逐字说出目标表达，如果来自教练提示或跟读，也不能算独立完成。

## 传达性 Communication

- 1：核心意思大部分无法传达，严重依赖中文或教练给出完整答案。
- 2：能传达部分简单信息，但经常依赖关键词、句首、选项或完整答案，核心任务未独立完成。
- 3：基本完成主要沟通目标，偶尔误解、遗漏或需要重新说明。
- 4：清楚完整地传达主要信息，能独立处理一般追问和简单变化。
- 5：准确、自然、有效地传达复杂信息，并能根据对方反应调整表达。

Communication 看用户能否完成交流，而不是统计用户问了多少问题。大量单句提问不自动构成高分；能回应对方追问、连续说明问题、确认理解并处理条件变化，才是更高等级证据。

## 流利度 Fluency

- 1：频繁长停顿，难以组成完整句子或维持对话。
- 2：停顿和重复明显，严重依赖提示或跟读，只能使用短句逐步表达。
- 3：能持续完成对话，但复杂内容中仍有明显停顿、自我修正或重复。
- 4：大部分表达连贯，偶尔选词停顿且不影响交流节奏。
- 5：表达持续、自然、稳定，能适应打断和话题变化。

大量关键词式回答、未完成句、依靠教练代为补全，以及对方稍作追问就无法继续，都应影响 Fluency；不能因为对话轮数多或教练一直成功猜到意思就判为流畅。

## 发音 Pronunciation

- 1：大量语音难以辨认，经常需要重复。
- 2：明显发音问题较多，偶尔造成误解。
- 3：大部分可听懂，长音、促音、拨音、节奏或语调偶尔不准确。
- 4：发音清楚，节奏与语调整体自然，很少需要重复。
- 5：发音清晰稳定，音拍、节奏和语调控制良好。

发音只能依据本次 Voice 中实际听到的表现。生成总结时只要仍有具体、可信的实际听觉证据就可以评分；如果只能依据文字转写，或无法说明具体听觉证据，则返回 `null`，并将 `confidence` 设为 `insufficient`。不能从文字转写推断发音，不把转写偏差判为用户错误。有效证据应尽量指出具体词及长音、促音、拨音、音拍、节奏、语调或实际造成的误解；“有些发音不稳定”本身不是充分证据。

## 完成与补强判定

- `session.completed`：用户已明确结束当天主题并要求提交总结。
- `coreGoalAchieved`：判断训练场景中的整体沟通结果，与是否提交总结、是否逐字说出目标表达是不同概念。任务明确列出核心任务时按核心任务判断；没有单列时，从训练场景推导用户应完成的沟通结果。主要场景和大多数核心沟通任务独立完成或在二次验证中独立完成时应为 `true`。自然同义表达同样有效；个别一至两个参考表达未使用或仍是弱句，只进入句子复习和下一步重点。只有主要场景没有完成、多个核心沟通任务普遍依赖提示／完整答案，或关键沟通发生中断时才为 `false`。
- 任一有效评分 ≤2：必须建议补强。
- `coreGoalAchieved=false`：必须建议补强。
- 三项有效评分均 ≥3 且 `coreGoalAchieved=true`：不建议补强。
- Pronunciation 为 `null` 只表示证据不足，不单独触发补强。

对于任务类型已经是 `reinforcement` 的课程，如果主要流程和大多数核心目标已经独立完成，只把剩余弱句写入复习，不因单个复杂句再次建议完整主题补强。只有多个主要目标仍未完成、普遍依赖提示或关键沟通持续中断时，才再次使用 `coreGoalAchieved=false`。

评分与文字证据必须一致：不得一边写“所有主要目标独立完成”一边把 `coreGoalAchieved` 设为 `false`；不得在用户使用过中文时声称“没有切换中文”；Pronunciation 为 `null` 时不得断言未经证实的具体发音错误；没有二次验证时不得写“已经掌握”。

补强原因代码只允许：

- `COMMUNICATION_LOW`
- `FLUENCY_LOW`
- `PRONUNCIATION_LOW`
- `CORE_GOAL_NOT_ACHIEVED`
