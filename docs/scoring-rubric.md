# JSOS 固定评分标准 v1.0

三项能力均采用 1～5 分；证据不足使用 `null`。不得为了鼓励而虚高评分，两个等级之间选择较低等级。评分依据只来自当前聊天中的实际训练。

完成状态定义：

- 独立完成：没有获得关键词、句首、选项或完整答案，仅通过真实交流中的正常重复、澄清而完成。
- 提示完成：获得关键词、句首或选项后完成。
- 跟读完成：教练给出完整句后复述。

跟读完成不能作为独立能力证据；提示完成只能作为有限能力证据。帮助后更换条件进行二次验证并独立完成，才可按独立完成计入评分。

## 传达性 Communication

- 1：核心意思大部分无法传达，严重依赖中文或教练给出完整答案。
- 2：能传达部分简单信息，但经常依赖关键词、句首、选项或完整答案，核心任务未独立完成。
- 3：基本完成主要沟通目标，偶尔误解、遗漏或需要重新说明。
- 4：清楚完整地传达主要信息，能独立处理一般追问和简单变化。
- 5：准确、自然、有效地传达复杂信息，并能根据对方反应调整表达。

## 流利度 Fluency

- 1：频繁长停顿，难以组成完整句子或维持对话。
- 2：停顿和重复明显，严重依赖提示或跟读，只能使用短句逐步表达。
- 3：能持续完成对话，但复杂内容中仍有明显停顿、自我修正或重复。
- 4：大部分表达连贯，偶尔选词停顿且不影响交流节奏。
- 5：表达持续、自然、稳定，能适应打断和话题变化。

## 发音 Pronunciation

- 1：大量语音难以辨认，经常需要重复。
- 2：明显发音问题较多，偶尔造成误解。
- 3：大部分可听懂，长音、促音、拨音、节奏或语调偶尔不准确。
- 4：发音清楚，节奏与语调整体自然，很少需要重复。
- 5：发音清晰稳定，音拍、节奏和语调控制良好。

发音只能依据本次 Voice 中实际听到的表现。证据不足时返回 `null`，并将 `confidence` 设为 `insufficient`；不能从文字转写推断发音，不把转写偏差判为用户错误。

## 完成与补强判定

- `session.completed`：用户已明确结束当天主题并要求提交总结。
- `coreGoalAchieved`：判断主题整体的核心沟通能力，与是否提交总结是两个概念。主要沟通流程能够独立完成，且大多数核心目标已独立完成或在二次验证中独立完成时应为 `true`。个别一至两个弱句只进入句子复习和下一步重点，不因此把整个主题判为 `false`。只有核心任务无法独立推进、多个主要目标普遍依赖提示／完整答案，或关键沟通发生中断时才为 `false`。
- 任一有效评分 ≤2：必须建议补强。
- `coreGoalAchieved=false`：必须建议补强。
- 三项有效评分均 ≥3 且 `coreGoalAchieved=true`：不建议补强。
- Pronunciation 为 `null` 只表示证据不足，不单独触发补强。

补强原因代码只允许：

- `COMMUNICATION_LOW`
- `FLUENCY_LOW`
- `PRONUNCIATION_LOW`
- `CORE_GOAL_NOT_ACHIEVED`
