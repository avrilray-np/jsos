# JSOS V1.1 实施与验收计划

## 第一阶段：现有问题修复

- 「昨日复习」按当前打开任务的日期读取其前一个训练日（例如 Day 8 读取 Day 7），合并总结记录与用户手动记录并去重；为空时显示「昨日完成很好，无需复习」。
- 总结导入先原样执行标准 JSON 解析；仅失败后谨慎修复结构弯引号，并保留明确解析错误。
- 总结弹窗的「稍后处理」改为「清除」；清空输入和错误但不关闭弹窗，空内容时不可点击。
- 总结只允许在对应训练日提交或重新导入；凌晨 1:00 切换训练日后，前一天及更早任务关闭提交。
- 返回按钮显示实际上一层名称；直接进入页面时使用约定的默认父页面。
- 四份 GPT‑Live 规范全员统一，删除固定个人等级／领域画像，保留现场自适应规则和每日指令内容。

## 第二阶段：多用户基础功能

- 管理员在 Supabase 创建内测账号；完成登录、首次密码提示和永久修改密码入口，不开放公众注册或邀请链接。
- 完成反馈提交、截图限制、未读／已读状态和管理员查看入口。
- 增加临时文字版使用指南，并落实页面与数据库双层权限校验；最终图文和录屏指南延期到 V1.2。

## 第三阶段：自定义计划与后台生成

- 新增计划草稿、主题行、生成任务、错误编号和幂等状态。
- Step 1 一次生成全部主题，允许逐项修改；60 秒仍未完成时显示「主题生成暂时中断」和「重新生成」。
- 确认主题后立即弹出「现在开启计划」，选择 Day 1 开始日期；暂不创建时日期保持为空。
- 开启后后台执行 Step 2，生成每一天的完整训练内容；未完成的当天任务提示「5分钟后可用」，失败内容在点击主题时无感重试。
- 新计划按新开始日期创建并归档旧计划；归档计划本期不提供查看入口。
- 所有未顺延日期均可提前进入任务预览；未来任务可查看内容和复制提示，但不能打卡或导入总结，不影响完成、顺延和补强。

## 第四阶段：Gemini 生成服务

- 在已关联 Google Cloud 赠金的项目中部署 Gen2 Cloud Function `jsos-gemini-endpoint`，使用 `gemini-2.5-flash`。
- 使用专用低权限服务账号和 ADC 调用 Agent Platform Gemini，不创建长期 API 密钥、不放宽组织安全策略。
- JSOS 后端通过受控鉴权调用生成服务；定义主题和每日内容的结构化 Schema、超时、重试、错误编号和用量限制。
- 使用每分钟 Scheduler 检查队列，每批最多并行 6 个 Day；空队列不调用 Gemini。

## 第五阶段：上线验收

- 本地完成构建、代码检查、单元测试和关键流程测试。
- 审核并应用 Supabase 迁移，再部署生成服务和 JSOS。
- 用试用账号验收首次建计划、日期、后台生成、失败恢复、切换计划、历史词句累计、昨日复习和反馈权限。
- 使用 60 天真实计划完成生产验收，包含三次临时失败自动恢复、未来任务预览和后台队列清空。
- 配置 Google Cloud 预算提醒并检查 Gemini 与 Gen2 Cloud Function 实际费用。
